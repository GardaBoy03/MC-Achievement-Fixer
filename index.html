Bedrock Edition • level.dat Tool

👋 Halo! Tool ini membantu mengaktifkan kembali World Achievements pada dunia Minecraft Bedrock kamu yang sudah ter-nonaktif.

Achievement biasanya nonaktif karena salah satu dari ini pernah terjadi di world kamu:

  • Pernah dibuka di Creative mode
  • Pernah mengaktifkan Cheats/Allow Cheats
  • Pernah mengaktifkan salah satu Experimental Gameplay toggle
  • World masih memakai behavior pack / resource pack (add-on)

Status "disabled" ini tetap tersimpan di file world meskipun semua opsi di atas sudah dimatikan/dilepas secara manual di dalam game.

Cara siapkan file world untuk diupload:
1️⃣ Cara termudah: di dalam Minecraft, buka Settings world → Export → simpan sebagai .mcworld
2️⃣ Cara manual: masuk ke folder minecraftWorlds di atas, cari folder world kamu (nama acak seperti kode), lalu kompres/zip seluruh folder tersebut dan ganti ekstensinya jadi .mcworld
3️⃣ Upload file .mcworld itu langsung di bawah ini 👇

⚠️ Selalu backup world kamu dulu sebelum diproses. Tool ini mengubah beberapa flag di level.dat dan bisa melepas behavior/resource pack dari world.

Jika world kamu bergantung pada blok/item custom dari add-on, atau dibuat dengan Experimental Gameplay, konten tersebut berpotensi berubah jadi "unknown"/hilang setelah pack dilepas. Achievement akan aktif, tapi cek dulu world-nya baik-baik sebelum dipakai permanen.
